

This document defines the complete UI/UX design specification for the Client Communication Agent System — a dark-theme SaaS dashboard enabling non-technical Indian retail business owners to manage AI-powered WhatsApp broadcasts and serve clients through a 24×7 intelligent assistant bot.

1. Design Overview
The operator dashboard is a desktop-first, dark-theme SaaS interface that gives a non-technical retail business owner full control over their WhatsApp broadcast campaigns, client base, knowledge base, and AI bot performance — all from a single centralized workspace. The design prioritises minimal cognitive load, fast navigation, and clear information hierarchy through a card-based layout with high-contrast visuals.

2.3 Spacing & Grid

Base grid: 8px. All component dimensions, padding, and margins are multiples of 8px. Cards follow a 12-column grid within the main workspace area.

3. Layout Structure
The dashboard uses a three-zone layout: a fixed left sidebar for global navigation, a persistent top header bar for search and account controls, and a fluid main workspace for content. All zones are visible simultaneously on desktop (1280px+).

3.1 Layout Zones

3.2 Left Sidebar Navigation


Sidebar behavior:
Active item: left border accent (4px, accent color) + background highlight
Hover: subtle background lift (surface alt color)
Collapsed state: icon only, tooltip on hover with label
Bottom of sidebar: user avatar, name, and plan badge
WhatsApp quality rating indicator: Green / Yellow / Red dot always visible in sidebar footer

3.3 Top Header Bar
Height: 64px. Background: surface color. Bottom border: 1px solid border color.


3.4 Main Workspace
Padding: 24px. Max content width: 1440px (centered). Cards use a 12-column CSS grid with 16px gutters. On tablet (768–1279px): 8 columns. On mobile (<768px): single column stacked.
